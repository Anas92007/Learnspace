# Learn Space

Learn Space is a static learning platform website built with HTML and CSS.

## Pages

- `index.html` — Home
- `courses.html` — Course catalog
- `learning-paths.html` — Learning paths
- `about.html` — About Learn Space
- `login.html` and `signup.html` — Frontend-only authentication demos

The site uses local images in `assets/images/`, plus Bootstrap and Google Fonts
from their CDNs. Login and signup are visual prototypes and do not create or
authenticate accounts.

## Run locally

Open `index.html` in a browser, or serve the project root with any static web
server.

## Deploy to Netlify

Connect this repository to Netlify. The included `netlify.toml` publishes the
project root; no build command is required.
